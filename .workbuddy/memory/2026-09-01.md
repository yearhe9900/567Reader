## MPP → Android Compose 移植 API 陷阱（重要）
- 工程 Compose 为 **BOM 2025.08.00 = Compose 1.12.0**（新版本）。
- 官方 AndroidLiquidGlass 是 **Compose Multiplatform (commonMain)** 工程，其 `DampedDragAnimation.kt` 用顶层 `awaitFrame()`（无 import）。该符号 **以及** `androidx.compose.ui.graphics.withFrameNanos`、`androidx.compose.ui.graphics.MonotonicFrameClock` 在 **Android-only Compose 1.12 的 `androidx.compose.ui.graphics` 顶层均解析不到**（帧时钟顶层 API 已被移走；同包 `Color` 等仍能解析，说明只是帧时钟类被挪走，非 ui-graphics 缺失）。
- **最终可用修复**：`DampedDragAnimation` 内实现私有 `suspend fun awaitFrame() { yield() }`，`import kotlinx.coroutines.yield`。`yield()` 让出协程槽等价于等一帧机会；真正等待动画落位由后面的 `snapshotFlow{value}.filter{}.first()` 在帧上收集完成。规避所有 Compose 帧 API 版本差异。
- 经验：移植 Compose Multiplatform catalog 代码到 Android 1.12 时，帧同步/动画时钟的 MPP 顶层函数（`awaitFrame`/`withFrameNanos`/`MonotonicFrameClock`）不能直接搬，用 `kotlinx.coroutines.yield()` 兜底最稳。
- 注：本地 Gradle 缓存（`~/.gradle/caches`）仅含 `.module`/`.pom` 元数据，无实际 AAR，无法反查符号，遇到 API 差异需靠版本无关写法兜底。

## 玻璃对话栏/删除弹框视觉与弹出的两处修复
- **根因1（背景色/透明度不一致 + 边缘无光圈）**：`GlassAlertDialog` 与 `LiquidDialog` 之前都把 dim 遮罩层 `drawWithContent{ drawContent(); drawRect(dimColor) }` 套在**卡片外层 Box** 上，导致 `drawRect(dimColor)` 画在卡片之上，把卡片整体压暗、并盖住 `Highlight.Plain` 边缘高光（光圈）。官方 `DialogContent` 的 dim 只盖在壁纸 Image 层，卡片是独立兄弟节点画在其上。
- **修复**：两个文件均改为三层结构 —— ①`Image(layerBackdrop) + drawWithContent{dim}` 仅盖背景；②独立 `Box(fillMaxSize, clickable=取消, contentAlignment=Center)` 内放 `Column(drawBackdrop 卡片)`。卡片不再被压暗，光圈显现。`GlassAlertDialog` 卡片圆角改回官方 `RoundedRectangle(48.dp)`（此前误用 32.dp）。
- **根因2（删除弹框"切换新页面"）**：`GlassAlertDialog` 是 DialogFragment（覆盖层不切 Activity），但其 backdrop 采样源是**全屏 wallpaper_light 壁纸**，把整页书详情遮住 → 视觉像换页。
- **修复**：`BookInfoActivity.deleteBook()` 在弹框前用 `window.decorView.draw(Canvas(bitmap))` 截取**原页面**截图，经 `newInstance(backdropBitmap=...)` 传入；`GlassAlertDialog` 有截图时用 `BitmapPainter(bitmap.asImageBitmap())` 作 backdrop 采样源、无截图回退 wallpaper_light。玻璃卡片现采样真实页面 → 在原页面上弹出。`Bitmap`/`Canvas` import 已加。
- 验证：`asImageBitmap()` 需 `androidx.compose.ui.graphics.asImageBitmap`，`BitmapPainter` 需 `androidx.compose.ui.graphics.painter.BitmapPainter`，均已导入（未代跑构建，按用户习惯给命令）。
