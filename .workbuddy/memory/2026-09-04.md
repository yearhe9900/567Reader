## UI 层排查：View vs Compose 化程度
- 项目 215 个 XML 布局（15,675 行）、~250 个文件使用传统 View、~135 个 Fragment（其中 129 个 DialogFragment）。
- 已 Compose 化：主界面壳（MainScreen + 三页 + 底部导航栏 + 玻璃弹框系统），约 13 个 @Composable 文件 / 4,600 行，占 UI ~15%。
- **不应迁移**（~19,500 行）：阅读器（Canvas 手绘翻页 14,878 行）、漫画阅读器（2,675 行）、视频播放器（1,046 行）、WebView（669 行）。
- **建议迁移**（~15,000 行 + ~100 布局）：简单 DialogFragment（~40 个）、设置页配置 Fragment（5 个 1,901 行）、搜索/书源/书信息等页面。
- 最快收益：批量迁移 ~40 个简单 DialogFragment → Compose，一举删 ~40 个 XML 布局。
