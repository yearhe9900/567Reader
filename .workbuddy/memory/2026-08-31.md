# 2026-08-31

## 移除在线检测更新功能
567Reader（Legado/阅读Sigma fork，包名 com.qreader.reader）移除了在线检测更新功能。

删除的源码：
- `app/src/main/java/com/qreader/reader/help/update/` 整个目录（AppUpdate.kt / AppUpdateGitHub.kt / AppUpdateGitee.kt / AppReleaseInfo.kt）
- `app/src/main/java/com/qreader/reader/ui/about/UpdateDialog.kt`
- `app/src/androidTest/java/com/qreader/reader/UpdateTest.kt`
- res 资源：`menu/app_update.xml`、`layout/dialog_update.xml`、`drawable/ic_update.xml`

关键点：
- `AppVariant` 枚举原本定义在 `AppReleaseInfo.kt`，但被 `AppConst.kt`（签名识别正式/测试版）使用，已**迁移**到 `constant/AppConst.kt`（同包），并删除了无引用的 `isBeta()` 方法。
- `@string/auto_update`（"自动更新"）被 `dialog_rule_sub_edit.xml`（规则/订阅自动更新开关）复用，**需保留**；本次只删了 app 自动更新相关的 `auto_update_summary` 等。
- 保留：`update_log`（本地更新日志 changelog 展示，非在线）、`upVersion()` 里版本变更时显示本地 help/updateLog.md 的分支、`Download` model（WebView/RSS 等多处复用）。

清理的引用点：
- `MainActivity.kt`：upVersion() 里移除 autoUpdateVariant/lastCheckUpdate 自动检测块 + 相关 import（含 `kotlin.time.Duration.Companion.hours`）
- `AboutFragment.kt`：移除 check_update 点击分支、checkUpdate() 方法、waitDialog、lifecycleScope/AppUpdate/WaitDialog import
- `AppConfig.kt`：删 updateToVariant、autoUpdateVariant
- `LocalConfig.kt`：删 lastCheckUpdate
- `PreferKey.kt`：删 updateToVariant 常量
- `res/xml/about.xml`：删 check_update 项
- `res/xml/pref_config_other.xml`：删 updateToVariant、autoUpdateVariant 两项
- `res/values/arrays.xml`：删 default_app_variant / default_app_variant_value
- 8 个语言 strings.xml：删 check_update / check_update_interval / update_to_variant_title+summary / auto_update_summary / default_version / beta_release_version / beta_releaseA_version / beta_releaseS_version（auto_update 保留）
